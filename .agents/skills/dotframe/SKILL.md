name: dotframe
description: Build, test, and export Crafter Smash with the dotframe CLI. Use when changing gameplay, simulating or replaying matches, checking a render, debugging netplay desyncs, or building and deploying web, Discord, iOS, or macOS.
---
Run `dotframe skills get core` before any dotframe command. It matches the installed CLI version.
List the specialized guides with `dotframe skills list` (netplay, export-web, discord, ios, relay, assets, ...).
